# Todo List Application

## Project Description
This is a simple task management application developed using Python.

The application allows users to manage their daily tasks through a command-line interface.

## Features
- Add new tasks
- Display all tasks
- Delete tasks
- Mark tasks as completed
- Save tasks in a JSON file
- Load saved tasks when the application starts

## Technologies Used
- Python
- JSON
- Git
- GitHub
- Visual Studio Code

## Project Structure

```text
Todo-List/
├── main.py
├── tasks.json
└── README.md
```

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Open the terminal.
5. Run the following command:

```bash
python main.py
```
